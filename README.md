# Dashboard de Instrumentos de Higiene Ocupacional

## 📌 Sobre o Projeto

Este projeto apresenta um dashboard desenvolvido em Power BI para monitoramento e gestão dos instrumentos de Higiene Ocupacional da empresa fictícia Alpha Construções.
O objetivo foi centralizar informações sobre:

- Situação de calibração dos equipamentos;

- Controle de vencimentos;
  
- Distribuição geográfica dos ativos;
  
- Custos com calibração;
  
- Apoio à tomada de decisão para redução de despesas e otimização dos recursos disponíveis.

## 🎯 Problema de Negócio

Equipamentos com calibração vencida não podem ser utilizados para emissão de laudos e documentos legais de Segurança do Trabalho, impactando diretamente a capacidade operacional da empresa.

Além do aspecto legal e normativo, equipamentos ociosos ou mal distribuídos entre filiais podem gerar gastos desnecessários com novas calibrações e aquisições.

## 🔍 Insights Obtidos

### 1. Quase metade dos equipamentos está vencida

49,2% dos instrumentos encontram-se com a calibração vencida.
Impacto:

- Impossibilidade de emissão de laudos válidos;

- Risco de não conformidade legal;
  
- Redução da capacidade operacional das equipes de SST.

### 2. Apenas 42,8% dos equipamentos estão aptos para uso

Menos da metade do parque de instrumentos está plenamente disponível para realização de medições ocupacionais.

### 3. Oportunidade de revisão do inventário

Antes de investir em novas calibrações, é recomendada uma análise de utilização dos equipamentos para identificar:

- Equipamentos ociosos;

- Equipamentos duplicados;
  
- Necessidade real de cada filial.

### 4. Compartilhamento entre filiais

Uma estratégia de remanejamento de instrumentos pode reduzir custos, especialmente para equipamentos utilizados apenas em avaliações pontuais.
